OAT Firmware 0.1.3-beta

- Factory Reset 명령 기본값을 :XFR# 로 채웠습니다(펌웨어의 'Perform a Factory Reset',
  OATControl도 동일 명령 사용). 기존에는 사용자가 직접 찾아 입력해야 했습니다.
- '최신 릴리스 확인' 버튼 추가: GitHub releases/latest 태그를 조회해 현재 소스 버전과 비교하고,
  버전 패널에 표시합니다. 전환은 기존 '버전/브랜치' 선택으로 합니다.
- 0.1.2의 git 기반 버전 관리(증분 업데이트/태그 고정/소스 복구)는 그대로 유지됩니다.
