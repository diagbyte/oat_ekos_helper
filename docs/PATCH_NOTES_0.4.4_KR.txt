OAT Tools 0.4.4-beta — 간단 모드

기능이 늘어나면서 화면이 복잡해진 문제를 정리했습니다. 기능은 그대로 두고 표시만 줄입니다.

[간단 모드 (기본값)]
- 탭 3개만 표시: 촬영 준비 / Home / AutoPA. 평소 촬영은 이 세 개로 끝납니다.
- Home 탭에서 숨기는 항목: PARK, DEC 전원 OFF 위치로, UNPARK,
  DEC 오프셋 EEPROM 저장 옵션, 연결 시 자동 실행 옵션, RA Correction 고급 캘리브레이션.
- AutoPA 탭에서 숨기는 항목: AutoPA 축 위치 / 기준점(Zero 저장).
- 남는 것: HA 갱신 → RA AutoHome → 미세조정 → SET HOME → GO TO HOME → 긴급 정지,
  저장된 DEC Home 복원, PAA 자동 보정과 수동 ALT/AZ 이동, PAA 로그 진단, 체크리스트.

[고급 모드]
- 상단 상태바의 '고급 ▸' 버튼 한 번으로 전체 탭(컨트롤러/모니터/축 보정/진단)과
  숨겨둔 항목이 모두 나타납니다. 선택 상태는 저장되어 다음 실행에 유지됩니다.

[동작 변경 없음]
- 숨긴 기능은 비활성화된 것이 아니라 표시만 되지 않습니다. 설정값(DEC 오프셋 모드,
  리밋, 연결 시 자동 실행 등)은 저장된 그대로 동작합니다.

평소 촬영 순서
  1) 전원 ON → Ekos 마운트 연결
  2) HA 자동 계산 + OAT 적용
  3) RA AutoHome 실행
  4) 필요하면 DEC 맞춘 뒤 SET HOME
  5) Ekos PAA 측정 → PAA 자동 보정 시작
  6) 촬영, 종료 시 GO TO HOME 후 전원 OFF
