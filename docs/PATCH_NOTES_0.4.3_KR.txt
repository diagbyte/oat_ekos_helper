OAT Tools 0.4.3-beta — OATControl 기능 이식

OATControl(OpenAstroTracker-Desktop) 소스를 분석해 OAT Tools에 없던 기능을 옮겼습니다.
모든 명령은 펌웨어 v1.13.9 소스로 존재를 확인했습니다.

[펌웨어 버전 게이팅]
- 연결 시 :GVN# 으로 펌웨어 버전을 읽어 상단 상태바에 표시합니다(FW: V1.13.9).
- OATControl과 같은 방식(1.13.9 -> 11309)으로 기능별 최소 버전을 판정해,
  지원하지 않는 버튼은 비활성화하고 툴팁으로 이유를 표시합니다.
  RA Hall AutoHome >= 1.9.21 / :XGC 타겟 계산 >= 1.9.0 / AZ·ALT Home >= 1.13.6

[펌웨어 DEC 리밋 연동 — Mount Monitor]
- :XGDL# 로 펌웨어가 실제 적용하는 DEC 리밋을 읽어 표시하고, 모니터 막대에 반영합니다.
  (기존에는 툴에 직접 입력한 값만 사용해 실제 클램프와 어긋날 수 있었습니다.)
- '현재 위치를 하한/상한으로'(:XSDLL# / :XSDLU#), '설정값으로 초기화'(:XSDLl# / :XSDLu#).

[타겟 도달 가능성 검사 — Mount Monitor]
- :XGC{RA}*{DEC}# 로 해당 좌표의 스테퍼 위치를 미리 계산해, 슬루 전에 DEC 펌웨어 리밋과
  RA 설정 범위를 넘는지 판정합니다. '현재 Ekos 좌표' 버튼으로 바로 채울 수 있습니다.
  (OATControl이 관심대상 목록마다 수행하는 계산과 동일한 명령입니다.)

[Park / Unpark / DEC 전원 OFF 위치 — Home 탭]
- PARK(:hP#): 실행 전 DEC 홈 오프셋이 0이 아니면 Park가 Home에서 더 움직인다는 경고를 표시합니다.
- UNPARK(:hU#).
- 'DEC 전원 OFF 위치로': 저장된 '전원 ON -> Home' 이동량을 반대로 적용해 다음 세션 시작
  위치로 되돌립니다(OATControl의 Goto DEC Park before Power Off와 동일 개념).

[DEC Home 오프셋 저장 방식 선택 — 중요]
- 체크박스 'DEC Home 오프셋을 마운트 EEPROM에 저장 (OATControl 호환)'을 추가했습니다.
  * 끔(기본, 0.4.2와 동일): SET HOME이 :XSHD# 를 0으로 정리 -> 펌웨어/Ekos Park가 Home에 정확히 정지.
  * 켬: SET HOME이 '전원 ON -> Home' 이동량을 :XSHD# 로 마운트에 저장(툴 재설치와 무관하게 유지,
    OATControl과 호환). 이 경우 펌웨어 Park는 오프셋만큼 DEC를 더 움직이므로 전원 OFF 전에는
    'DEC 전원 OFF 위치로' 버튼을 사용하세요. 저장 시 로그로 경고합니다.
- '저장된 DEC Home 복원'은 EEPROM 값이 있으면 그 값을, 없으면 툴 설정값을 사용합니다.

[Mini Controller]
- 슬루 속도 4단계 선택(:RS/:RM/:RC/:RG).
- 키보드 조작: 좌우 = RA, 상하 = DEC, W/S = ALT, A/D = AZ (컨트롤러 탭이 활성일 때).
- 트래킹 보정계수 읽기/저장(:XGS# / :XSS#)과 실제 트래킹 속도 표시(:XGT#).

[축 보정 완성 — Axis Calibration]
- 계산한 steps/degree 를 마운트에 직접 적용하는 ④ 버튼 추가(:XSR# / :XSD#).
  기존 값을 로그에 남기고, 기록 후 :XGR#/:XGD# 재읽기로 검증하며, 기존 대비 비율(%)을 표시합니다.
- 드리프트 얼라인(:XD{초}#) 실행 버튼 추가. 동/서 왕복이며 중단할 수 없어 사전 확인 대화상자를 둡니다.

[AutoPA]
- '첫 보정 전 2회 측정 대기' 옵션(기본 켬). OATControl과 동일하게 연속 두 번째 해부터 보정해
  슬루 직후 첫 솔브의 노이즈에 반응하지 않습니다.

[촬영 준비]
- 현장 점검 체크리스트(항목 편집 가능, 체크 상태 저장). 수평/정렬/케이블처럼 소프트웨어가
  확인할 수 없는 항목을 위한 것입니다.
- '연결 시 RA AutoHome', '연결 시 DEC Home 복원' 자동 실행 옵션.

[Diagnostics]
- DEC 리밋, 트래킹 속도/보정계수, LST, HA, 반구, 네트워크(:XGN#) 항목 추가.

[참고 — v1.13.9에 없어 넣지 않은 것]
- 트래킹 레이트 선택(:TQ/:TS/:TL/:TK/:TM)과 사용자 지정 Park 위치(:hS#)는 1.13.9 펌웨어에
  존재하지 않습니다(h 계열은 P/F/U/Z만 지원). 상위 펌웨어로 올릴 경우 추가하겠습니다.
