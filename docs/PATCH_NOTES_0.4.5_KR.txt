OAT Tools 0.4.5-beta — 종료 위치 (Release)

전원을 Home 자세에서 끄면 카메라 무게가 RA ring에 그대로 걸립니다. 종료 전에 DEC를
지정한 각도만큼 내려두는 동작을 Home 탭 ③ Final Home에 추가했습니다.

[종료 위치로 이동 (전원 OFF 전)]
- 'DEC / RA' 각도(Home 기준)를 지정합니다. 기본값 DEC -30°, RA 0°.
  렌즈를 아래로 내리려면 음수입니다.
- 버튼을 누르면 (선택에 따라) 먼저 GO TO HOME으로 Home에 맞춘 뒤, 지정 각도만큼 이동합니다.
- 이동 전 트래킹을 정지합니다.
- 이동 전에 펌웨어 DEC 리밋을 확인해, 지정 각도가 리밋 밖이면 실행하지 않고 안내합니다
  (그대로 두면 펌웨어가 이동을 잘라 엉뚱한 위치에 멈춥니다).
- 이동량이 명령과 다르면(리밋 클램프) 실패로 처리하고 로그에 남깁니다.

[다음 세션 자동 연계]
- Home에서 출발해 종료 위치로 이동한 경우, '저장된 DEC Home 복원' 값을 이 이동의 반대값으로
  자동 갱신합니다. 다음 전원 ON 위치가 바로 종료 위치이므로 값이 정확히 일치합니다.
  DEC 오프셋 EEPROM 모드를 쓰는 경우 :XSHD# 에도 함께 기록합니다.
- 따라서 다음 세션은: 전원 ON → '저장된 DEC Home 복원' → RA AutoHome → SET HOME 순서로
  DEC를 손으로 맞출 필요가 없습니다.
- Home이 아닌 위치에서 실행하면 복원값은 건드리지 않습니다.

[현재 위치 저장]
- 원하는 자세로 직접 옮긴 뒤 '현재 위치 저장'을 누르면 그 위치가 종료 위치로 기록됩니다.

권장 종료 절차
  GO TO HOME → 종료 위치로 이동 → 전원 OFF
